# Практическая работа №3 — резервное копирование

Акишев Ақжан Бақытжанұлы, вариант 1.

Основные файлы и инструкции находятся в [`practice1/README.md`](practice1/README.md).
Python 3.12+, сторонние библиотеки не нужны.

Для воспроизведения всех опытов распакуйте проект **в новую папку**, откройте в ней
терминал и выполните:

```bash
python run_demo.py
python -m unittest discover -s practice1 -p "test_*.py" -v
```

`run_demo.py` создаёт только учебные данные этого проекта, делает 8 копий с
двухсекундными паузами, проверяет повреждения, удаляет учебную `company_data/buh`
и восстанавливает её. Существующие данные и копии он не перезаписывает: повторный
запуск требует новой папки. Распаковка проекта в новую папку безопаснее ручного
удаления каталогов. Для одиночных запусков используйте `practice1/README.md`.

Папка `evidence/` содержит настоящие журналы выполнения и измерения, полученные
в облачном Linux-окружении 28.10.2026, а не на компьютере студента.
Сохранённые результаты не гарантируют такое же время и размер архива на другой ОС.
В `execution.log` строки `[FAIL]` в опытах с повреждением — ожидаемый успешный
результат проверки: программа обнаружила проблему.

Публичный репозиторий проекта: https://github.com/Imakind/practice3-backup-recovery.
Для сдачи можно использовать эту ссылку. В репозиторий не добавлены
`company_data/`, `backups/`, `restore_test/` и `experiments/`.
Эти каталоги исключены в `.gitignore`. Данные и архивы намеренно не входят в
архив исходного проекта: они создаются командами выше.
